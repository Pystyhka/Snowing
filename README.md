# Snowing ❄️

Программа для автоматического мониторинга снегопадов через OpenWeatherMap API.

## Описание

Приложение проверяет погодные условия каждый час и отслеживает наличие снега в указанном местоположении. Результаты сохраняются в таблицу с отметкой времени.

## Как это работает

1. **Каждый час** программа обращается к OpenWeatherMap API
2. **Проверяет** параметр `description` в погодных данных на наличие снега
3. **Записывает результат** в таблицу:
   - `YES` + время — если обнаружен снег
   - `NO` + время — если снега нет
